OFFLINE PREVIEW — NOT A SHAREPOINT SITE

This page runs the web part bundle from the last build against a simulated SharePoint host. Lists, permissions and the signed-in user are fictional, submissions stay in this tab, and all external network access is blocked.

“Connected” and “received” labels below refer only to the simulation; no approvals run and no AI service is connected. Drafts may remain in this browser’s local storage.

Preview role simulation; production resolves the role from identity. The simulated site groups behind this switch answer the same request the web part makes on a real site, and the shipped bundle reads no role out of the address.

Usage rows and the open incident shown in the telemetry strip are fictional sample data seeded by the simulation, as are the three requests of the preview person on Status.
