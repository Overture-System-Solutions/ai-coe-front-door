WHAT THIS ADDS
A read-only custom connector for the Anthropic Admin API (usage report and cost report) and a
scheduled flow, "OSS Demo - Claude Telemetry", that every six hours writes one AI Usage Daily row
per day (cost, USD) and per day and model (completions: input and output tokens) with Provider =
anthropic, for the previous month and the month to date. It also keeps a settable spend alert:
the ClaudeMonthlyBudgetUsd row of AI CoE Configuration (created empty on the first run) is the
budget; when month-to-date spend exceeds it a Cost incident opens in AI CoE Incidents, and it is
resolved once spend is back under budget. The front door web part 1.0.0.9 shows these rows and
the incident when its "Usage metrics provider" property is Claude (the default) or both.

SCOPE AND BOUNDARIES
- Anthropic: read-only (Admin API usage_report/messages and cost_report). No Messages, keys or
  members are touched. The connection holds the only copy of the admin key.
- SharePoint writes: AI Usage Daily rows with Provider anthropic (upserted by CompositeKey), the
  ClaudeMonthlyBudgetUsd row of AI CoE Configuration, and one Cost incident in AI CoE Incidents.
- No draft, case, approval or email changes. The Claude draft connector and flow, the OpenAI
  files and the demo flows are unchanged; the OpenAI usage feed is not ingested by this package.
- Locally checked only: 17 checks, 16 passed and 1 skipped until the flow is bound. Nothing was
  imported, no key collected, no tenant write performed. See VERIFICATION.json, CHANGES.md and
  TESTING.md.
