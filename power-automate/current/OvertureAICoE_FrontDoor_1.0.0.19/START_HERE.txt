BEFORE YOU START
  The AI CoE Approved Tools list must exist on the site. If you have not done it yet, do
  ..\START_HERE_OvertureAICoE_1.0.0.2.txt first (import OvertureAICoE_1_0_0_2.zip, run SharePoint Provisioning
  once, check the list's permissions). Without the list the front door still works: the approved-tools panel says
  "The approved tools could not be read on this site." and the tool check treats every tool as not on the list.

STEPS
  1. SharePoint admin center > More features > Apps > App Catalog > Apps for SharePoint > Upload
     overture-ai-coe-front-door.sppkg > Replace it. In the dialog, keep "Enable this app and add it to all sites"
     as it was for 1.0.0.17, then Enable. No new API access request comes with this version.
  2. On the OvertureAICoE page that holds the front door: Edit > select the web part > edit (pencil) > the
     "AI drafting" group:
       AI CoE Concierge chat link:
         https://m365.cloud.microsoft/chat/?titleId=T_90a94581-0aa2-7ff7-625d-5fe358e84502&source=agentCenterDialog
       AI CoE Concierge add link (Teams):
         https://teams.microsoft.com/l/app/?titleId=T_90a94581-0aa2-7ff7-625d-5fe358e84502
     Leave the other fields as they are. Republish the page.
  3. Hard-refresh the page (Ctrl+F5). The tabs should read Home, Requests, Improvement, Marketing ... Cases,
     Metrics, Admin. If they still say Engineering, the old bundle is cached: wait a few minutes and refresh again.
  4. Add the tools the AI CoE has reviewed to AI CoE Approved Tools (Site contents > AI CoE Approved Tools > New).
     Status is Approved, Approved with conditions, Not approved or Under review. Fill what it is approved for, the
     yes/no allowances, conditions and Last reviewed. A blank yes/no means no. Add at least one row so step 6 has
     something to show.
  5. In Copilot Studio, add the AI CoE Approved Tools list to the AI CoE Concierge's knowledge if it is not there
     yet (development/copilot-agent/OvertureAICoE_AI_CoE_Assistant/START_HERE.md, step 3), then publish the agent
     again.
  6. Check it as a member, not only as an owner:
     a. Requests: "Start a request" at the top with its four cards in a row; My requests below in two columns; a
        request's title opens its item in a new tab.
     b. Home: Approved tools at the bottom lists your rows with the right status.
     c. Check a tool or task: the first screen lists your tools by name. Pick one and finish; the result matches its
        row (for example a Not approved tool says a review is needed).
     d. Home: type a question, Ask the AI CoE. The first time choose "Open the AI CoE Concierge"; Copilot chat opens
        on the agent; paste with Ctrl+V and send.
     e. Submit one short request; the receipt offers "Continue in the AI CoE Concierge".
     f. As a member, open the AI CoE Approved Tools list: rows can be read, New is refused or missing.
     g. Cases: no box about cases being saved through a configured service.
  7. Tell Julianna what you saw (or a screenshot of anything wrong). Then CloudWave gets the same package.
