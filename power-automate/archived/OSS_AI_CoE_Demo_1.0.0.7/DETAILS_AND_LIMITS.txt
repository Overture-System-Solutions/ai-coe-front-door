WHAT WAS CORRECTED

- All SharePoint operations target CloudWaveDashboardDemo, not AI-CoE-Lab.
- New solution/publisher, workflow IDs and connection-reference names isolate
  this demo from the original solution's components in the same environment.
- All emails and approval assignments are pinned to Sam; reassignment is off.
  This is a demo containment choice, not production business-owner routing.
- Intake preserves a nonempty CoEID from front door 1.0.0.7 and receipts use it.
  The original flow always replaced that ID. The app also has a title-based
  fallback association, but preserving its actual ID avoids relying on that.
- Provisioning only creates a missing list/field after a successful empty lookup;
  a permission error or timeout is no longer treated as evidence of absence.
- Recurring runs and per-case/list loops are serialized to limit overlap during
  this small demo. A waiting approval can hold later review work; respond promptly.
- All workflow definitions are packaged OFF. Importing an update to an already
  running copy can preserve its live state; always check the actual state yourself.

WHAT THIS DOES NOT DO

- It does not add a live AI model. The inspected 1.0.0.7 summary buttons still
  return the non-AI summary before reaching the model-call path. An authenticated
  server-side model service and front-door code change remain separate work.
- It does not connect Claude/Copilot usage feeds, calculate ROI, install Enterprise
  Intelligence Home, operate CloudWave production, or publish any client report.
- It does not grant access, repair licensing/DLP, migrate existing records or
  prove live tenant readiness. This build was not imported or run in OSS here.
- The approval timeout is five days. An expired request needs deliberate recovery;
  do not auto-resubmit or reset flags without checking for a still-active approval.
- Core case and decision writes are separate operations. Failed writes require
  inspection/recovery; this is not a production exactly-once or rollback guarantee.
- The source query limits remain: 100 intake/triage cases, 25 review cases and
  500 digest rows. This package is for a small demo, not production-scale processing.
- Do not run another copy of the original core flows against the same demo lists.
